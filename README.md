# Dog & Cat Image Classifier
This project is a web-based Machine Learning application that identifies whether an uploaded image contains a Dog or a Cat. The application integrates a trained image classification model with a Flask backend and an interactive frontend.
Users can upload an image, preview it, and receive the predicted class along with the model's confidence score. The project demonstrates how a Machine Learning model can be integrated into a real-world web application.
Key Features:
Dog vs Cat image classification
Image upload and preview
Machine Learning-based prediction
Confidence score
Responsive web interface
Flask REST API
Input validation and error handling
Easy local deployment
Technologies: Python, Machine Learning, Flask, HTML5, CSS3, JavaScript.
